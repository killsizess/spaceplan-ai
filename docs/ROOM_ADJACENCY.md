# Смежность помещений — SpacePlan AI 0.20.0

02.11.2026. Производные связи между помещениями по стенам: какие комнаты граничат через стену, какой длины общий участок, какие двери их соединяют и какие двери ведут наружу. Это вход для будущих ограничений («кухня рядом с прихожей», «в спальню только через коридор») и для генератора планировок.

## Как увидеть

В режиме «По стенам» выберите помещение. В панели справа появится блок «Соседние помещения». В нём для каждого соседа указаны общая стена в метрах и двери между помещениями («дверь», «без двери» или число дверей). Сначала идут соседи с дверью, потом по длине общей стены. Нажатие на соседа выбирает его. Ниже показано, сколько дверей ведёт из помещения наружу.

## Правила

- Для каждой граничной стены помещения берутся участки его контура, лежащие на длинных гранях стены (с допуском 1e-6 м на округление полигонов), как отрезки вдоль оси стены.
- Два разных помещения смежны, если они лежат по разные стороны одной стены и их участки перекрываются на длине больше 1e-6 м. Общая длина — сумма перекрытий по всем таким стенам.
- Дверь на этой стене соединяет помещения, если её проём перекрывает общий участок. Окна помещения не соединяют.
- Дверь, у которой с одной стороны проёма есть помещение, а с другой нет, ведёт наружу. «Наружу» означает отсутствие замкнутого помещения: это может быть и незамкнутая зона внутри плана.
- Помещение по обе стороны отдельно стоящей стены не становится своим соседом, а дверь в такой стене не считается наружной.
- Результат отсортирован, симметричен и не зависит от порядка помещений, стен и проёмов. В формат он не сохраняется.

## Модель

`findRoomAdjacency(rooms, walls, openings)` в `src/domain/floor-plan/room-adjacency.ts` — чистая функция над помещениями (`id`, контуры, `boundaryWallIds`), стенами и проёмами. Возвращает пары `{ rooms, length, walls: [{ wallId, length, doorIds }], doorIds }` и наружные двери `{ roomId, doorId, wallId }`. Редактор вычисляет её один раз на состояние плана (`useMemo`) поверх уже рассчитанных помещений.

## Ограничения

- Смежность только через стены. Помещения, разделённые лишь зазором или касающиеся углом, не смежны.
- Двери, наполовину выходящие за общий участок, всё равно соединяют помещения, если перекрытие положительное.
- Проходы без двери (проём-арка) пока не моделируются: в формате есть только двери и окна.

## Проверки

Модульные тесты в `room-adjacency.test.ts`: квартира с перегородкой и ответвлением (длины 2,8 и 3,8 м, двери, вход), отдельно стоящая стена с дверью, полный список из 9 пар и всех дверей 3D-примера с входной дверью и участком 0,88 м между гостиной и кабинетом, симметрия и независимость от порядка. Браузерный сценарий `e2e/room-adjacency.spec.ts` проверяет блок в панели, порядок соседей, наружную дверь и переход к соседу.
