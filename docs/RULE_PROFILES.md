# Правила застройщика для любой страны — SpacePlan AI 0.33.0

Приложение рассчитано на разные страны. Готовая база норм есть только для Москвы (`RULES_MOSCOW.md`). Для любого другого места застройщик пишет правила своими словами в X-Ray, а приложение проверяет по ним план и варианты.

## Как это работает

1. В X-Ray выбрать «Другая страна или регион».
2. Написать правила и нажать «Применить правила».
3. Приложение показывает, как поняло каждую фразу, и отдельно то, чего не поняло.
4. План и варианты проверяются по понятым правилам, выводы ссылаются на исходную фразу.

Правила хранятся в плане (`ruleProfile`) и переходят в его варианты. Последний текст запоминается в браузере и подставляется в новый проект: это удобство, а не хранилище.

## Что понимается

| Правило | Примеры | Что проверяется |
|---|---|---|
| `room-min-area`, `room-max-area` | «кухня не меньше 9 м²», «kitchen at least 9 m2», «санузел до 6 м²» | Площадь помещений этого назначения |
| `room-count` | «две спальни», «минимум 2 спальни», «at least 3 bedrooms» | Число помещений |
| `min-height` | «потолки не ниже 2,6 м», «ceiling height at least 2.5 m» | Высота по самой низкой стене |
| `window-required` | «в каждой комнате окно», «every bedroom must have a window» | Окно наружу или на балкон |
| `no-merge` | «нельзя объединять кухню с гостиной» | Вариант: помещение накрывает оба прежних |
| `keep-bearing` | «несущие стены не трогать» | Вариант: несущая стена изменена |
| `keep-room` | «санузлы не переносить», «мокрые зоны не переносить» | Вариант: помещение перенесено или изменено |
| `project-required` | «любая перепланировка только по проекту» | Вариант: есть изменения |

## Границы

- **Это не нейросеть.** Разбор идёт по шаблонам на русском и английском. Текст на другом языке честно попадает в «не понято». Модель можно подключить позже вместо `interpretPrompt`: платные API только с согласия владельца, и модель будет лишь предлагать правила, а решать будет движок.
- **Непонятое не угадывается.** Голое «кухня 9 м²» без слова «не меньше» не считается правилом.
- **С законами страны ничего не сверяется**, и отчёт об этом говорит. Правила застройщика поэтому могут получать уровень «Проверено правилом»: они проверены как написаны, это не чтение чужого документа.
- **Единицы только метрические**, интерфейс пока только на русском.
