# Соединения стен — SpacePlan AI 0.8

22.10.2026. Диагностика существующей модели, без автоматического изменения геометрии.

## Возможности

Во вкладке «Стены» панель «Свободные концы» показывает каждую конечную точку без совпадающего конца другой стены. В 2D она отмечена оранжевой окружностью. T-касание середины стены отмечается ромбом. Для близкой цели показан пунктир.

Нажатие строки выбирает стену и центрирует нужный конец в 2D, сохраняя масштаб. Это работает и из 3D. Команда «Показать весь план» снимает фокус и снова вписывает геометрию. Фокус и маркеры не записывают изменение в план или историю.

Маркеры можно скрыть в «Настройки вида → Свободные концы стен». Список продолжает показывать фактическое состояние соединений. Нажатие строки снова включает маркеры, чтобы найденный конец был виден. Во время предварительного переноса узла маркеры скрываются, после отпускания или отмены пересчитываются по действующему плану.

## Что именно проверяется

- Концы на расстоянии не более 1e-9 м считаются общим узлом согласно существующим операциям редактирования.
- Для остальных концов ищется ближайший конец или внутренняя проекция на ось другой стены в радиусе 0,3 м.
- `open` — рядом нет такой цели.
- `near-endpoint` — ближайшая цель является концом другой стены.
- `near-wall` — ближайшая цель находится внутри её осевого отрезка.
- `junction` — конец касается середины оси с точностью до 1e-9 м, но общего редактируемого узла пока нет.

Собственная стена не считается целью. При равенстве расстояний предпочтение получает конец; оставшиеся равенства разрешаются по ID. Результат не зависит от порядка стен. Координаты возвращаемых точек скопированы; исходные объекты не меняются.

Число в панели — число несвязанных концов. Один небольшой разрыв между двумя окончаниями обычно даёт две записи. Одиночная отдельная стена имеет два свободных конца и может быть намеренной частью плана.

**Расстояние измеряется между осями, а не между физическими поверхностями стен.** Толщина может перекрывать это расстояние; помещение при этом иногда остаётся замкнутым и имеет рассчитанную площадь. Отсутствие свободных концов само по себе не доказывает правильность планировки. Диагностика не проверяет пересечения двух середин, строительные сопряжения, несущие конструкции или нормы.

## Состояние и совместимость

Диагностика вычисляется из `plan.walls`, не сериализуется и не создаёт вторую модель геометрии. Схема остаётся v3. Загрузка v1/v2, JSON, локальное хранение и история продолжают работать по прежним правилам. Новые зависимости и сетевые сервисы не добавлялись.

Радиус поиска — параметр чистого API `analyzeWallConnections`, по умолчанию 0,3 м. Проверяются конечные координаты, нулевая длина, уникальность ID и ограничение до 1000 стен. Толщина, высота и проёмы не участвуют в этом запросе; их проверяет существующая модель при редактировании.

## Проверки

Для финального состояния 0.8.0 прошли линтер, проверка типов, все **227 модульных тестов в 17 файлах**, все **47 браузерных сценариев** и производственная сборка. Семь новых сценариев повторно прошли против готовой сборки через `next start`.

Проверены закрытый контур, несовпадение концов на 0,1 м, исправление через координаты с общей отменой/повтором, T-касание и близость к середине стены без её разделения, JSON и перезагрузка. Скрытие и возврат маркеров проверены по реальным пикселям canvas; сохранённая запись и история остаются прежними.

Отдельный регрессионный сценарий проверяет ручное увеличение масштаба → 3D → выбор строки диагностики → точный центр в 2D с прежним масштабом → возврат ко всему плану. Начальное вписывание на новом 2D-холсте больше не перехватывает фокус. Проверены экран 390 px и отмена незавершённого переноса при переходе к диагностике.

Просмотрены `outputs/SpacePlan-AI-connections.png` и промежуточный мобильный снимок в `work/`. Для полного финального прогона использовалась отдельная папка результатов `work/playwright-final-080`, для производственной проверки — `work/playwright-production-080`.

Следующий небольшой шаг — явная команда соединения выбранных близких концов с общей проверкой и отменой. Автоматическое соединение всех замеченных точек в этой версии отсутствует.
