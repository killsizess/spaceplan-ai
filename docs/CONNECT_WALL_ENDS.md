# Соединение близких концов — SpacePlan AI 0.8.1

23.10.2026. Дополнение к диагностике версии 0.8: явная отменяемая команда изменения геометрии.

## Как использовать

Откройте вкладку «Стены» и найдите в панели «Свободные концы» запись с близким концом другой стены. Нажатие самой строки по-прежнему выбирает стену и показывает нужную точку в 2D. Отдельная кнопка «Соединить концы» переносит конец из этой строки точно к указанному концу другой стены. Целевая стена остаётся на месте. Радиус поиска — 0,3 м включительно.

У одного разрыва могут быть две строки и две кнопки: выбор строки определяет, какой конец переместится. Перенос меняет длину и, если требуется, направление исходной стены. Целевой конец может уже быть общим углом нескольких стен; эти стены не перемещаются.

После успешной операции диагностика, внутренние контуры, площадь и 3D-полы пересчитываются из общего плана. Действие занимает один шаг отмены, поддерживает повтор, автосохранение, перезагрузку и перенос JSON. Кнопка работает и при открытом 3D; положение камеры сохраняется.

## Проверки до изменения

Чистая функция `connectWallEndpoints(plan, diagnostic)` повторно проверяет обе стены, их конечные точки и текущую ближайшую цель. Если сохранённая диагностика устарела, конец уже соединён или ближайшей стала другая точка, команда отклоняется. При переносе используется точная текущая координата цели без округления и привязки к сетке.

Изменение проходит полную существующую проверку модели через `moveWallNode`. Нулевая длина стены, выход за пределы или проём, который больше не помещается в стене, отклоняют всю операцию. План, выбор, обе части истории и предыдущая сохранённая запись остаются прежними. Ошибка видна в рабочей области и рядом со списком соединений на мобильном экране.

Исходные объекты не изменяются. Формат остаётся v3; новая схема, миграция или отдельное хранилище связей не требуются. Новые зависимости и сетевые сервисы не добавлялись.

## Ограничения

Кнопка доступна только для диагностики `near-endpoint`. Отдельный конец без близкой цели, близость к середине стены и T-касание остаются диагностикой без команды соединения. Стены не разделяются автоматически. Соединение всех замеченных концов разом не выполняется.

Расстояние измеряется между осевыми точками. Перекрытие физических следов стен с учётом толщины иногда замыкает помещение ещё до соединения осей. Поэтому исчезновение двух свободных концов не обязательно создаёт новое помещение или увеличивает площадь. Геометрическая проверка не оценивает строительную допустимость.

## Проверено

Для финального кода 0.8.1 прошли `npm run lint`, `npm run typecheck`, `npm run build`, все **249 модульных тестов в 18 файлах** и все **52 браузерных сценария** в Microsoft Edge. Пять новых сценариев отдельно повторно прошли против готовой сборки через `next start`.

Контрольный пример с настоящим разрывом 0,25 м при толщине стен 0,2 м сначала не имеет помещения. Соединение верхнего конца к правой стене создаёт внутреннюю область 5,05 × 3,8 м и площадь **19,19 м²**. Проверены появление настоящего выбираемого 3D-пола, сохранение камеры, одна отмена и повтор. Обратное направление переноса меняет только выбранную стену; результат сохраняется после перезагрузки и экспорта/импорта отдельной копии JSON.

Отдельно проверены отказ при схлопывании стены, отказ из-за дверного проёма с сохранением исходной записи и истории, отсутствие кнопок для T-касаний/середин/дальних концов и доступность обеих команд на экране 390 px без горизонтального переполнения. Модульные проверки включают устаревшие снимки, изменение ближайшей цели, повтор команды, несколько стен в целевом углу, границу 0,3 м, точность координат, недопустимые значения и неизменяемость исходных данных.
